### 关键区别：小程序 vs 小游戏
- **入口文件**：小程序用 app.js，小游戏用 game.js
- **配置文件**：小程序用 app.json，小游戏用 game.json
- **项目类型**：compileType 从 "miniprogram" 改为 "game"
- **渲染方式**：小游戏直接使用 Canvas API
