# 项目记忆

## 五子棋微信小游戏

### 项目概述
一个支持双人实时对战的五子棋微信小游戏，支持创建房间、分享邀请、微信登录等功能。

### 技术决策
1. **项目类型**：微信小游戏（非小程序）
2. **前端框架**：使用微信小游戏原生开发
3. **绘图方案**：使用Canvas API绘制棋盘和棋子
4. **数据存储**：使用微信本地存储（wx.setStorageSync）
5. **通信方案**：使用WebSocket实现实时对战，支持房间管理和游戏状态同步
6. **服务器**：使用Node.js + ws库创建WebSocket服务器
7. **AppID**：wx5411a5407db6e264（已配置）
8. **云部署**：使用Render免费方案部署WebSocket服务器
9. **服务器地址**：wss://gobang-server-oycu.onrender.com
10. **GitHub仓库**：hugehenbeishang/gobang-game

### 关键文件
- `game.js` - 小游戏入口，包含完整游戏逻辑
- `game.json` - 小游戏配置
- `project.config.json` - 项目配置（compileType: "game"）
- `server/server.js` - WebSocket服务器，处理房间管理和游戏逻辑

### 开发规范
1. **文件命名**：使用小写字母和连字符
2. **代码风格**：遵循微信小游戏开发规范
3. **注释规范**：关键函数和复杂逻辑添加注释
4. **错误处理**：所有异步操作添加错误处理
