# 五子棋对战微信小程序

一个支持双人实时对战的五子棋微信小程序，支持创建房间、分享邀请、微信登录等功能。

## 功能特性

### 🎮 游戏功能
- **五子棋对战**：完整的五子棋游戏规则，支持15x15棋盘
- **实时对战**：双人实时对战，支持落子提示和悔棋功能
- **胜负判定**：自动检测五连获胜和平局情况
- **游戏控制**：支持重新开始、认输、分享等操作

### 👥 社交功能
- **微信登录**：使用微信账号快速登录
- **房间系统**：创建房间、加入房间、房间分享
- **好友邀请**：通过分享链接邀请好友加入对战
- **快速匹配**：随机匹配对手进行对战

### 🎨 界面设计
- **精美UI**：现代化的界面设计，渐变背景和卡片式布局
- **响应式**：适配不同屏幕尺寸
- **动画效果**：落子提示、加载动画等交互效果
- **暗色主题**：游戏界面采用深色主题，突出棋盘

## 使用说明

### 1. 项目配置
1. 在微信开发者工具中导入项目
2. 修改 `project.config.json` 中的 `appid` 为你的小程序AppID
3. 如果使用云开发，在 `app.js` 中配置云开发环境

### 2. 功能使用
1. **登录**：点击"微信登录"按钮进行登录
2. **创建房间**：输入房间名称，选择棋色，点击"创建房间"
3. **加入房间**：输入房间号，点击"加入房间"
4. **分享房间**：在房间页面点击"分享给好友"或复制房间号
5. **开始游戏**：双方准备就绪后，房主点击"开始游戏"

### 3. 游戏操作
- **落子**：点击棋盘交叉点落子
- **悔棋**：点击"悔棋"按钮（需要对方同意）
- **重新开始**：点击"重新开始"按钮
- **认输**：点击"认输"按钮
- **分享**：点击"分享"按钮分享当前游戏

## 技术实现

### 前端技术
- **微信小程序**：使用原生微信小程序开发
- **Canvas API**：使用Canvas绘制棋盘和棋子
- **响应式设计**：使用rpx单位适配不同屏幕

### 核心算法
- **胜负检测**：四方向扫描检测五连
- **AI评估**：基于位置评估的简单AI算法
- **棋盘渲染**：高效的Canvas绘制算法

### 数据存储
- **本地存储**：使用微信本地存储保存用户信息和房间状态
- **云开发**：支持微信云开发进行数据持久化（可选）
